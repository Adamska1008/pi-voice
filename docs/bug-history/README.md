## 后续记录约定

- 背景与现象：预期行为、实际行为、受影响版本及范围。
- 定位过程：关键证据、排除的假设；区分事实与推断。
- 根因与修复：调用链、变更文件、兼容性选择及修复提交。
- 验证：测试方法、结果、未验证部分和复测步骤。
- 后续：复测结果、剩余问题及相关提交；保留原始结论和修订日期。

只记录必要的技术摘要；不复制原始会话、音频、完整运行日志、凭据或个人配置。
没有真实链路证据时，不把单元测试或离线模拟标成线上验证完成。
