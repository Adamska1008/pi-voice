# 词表配置（开发中）

第一批只实现配置校验、读写及设置切换时保留；**运行时尚未使用这些值**。
提词、LRU 和快照仍使用当前 128/64/64 固定上限；菜单入口也尚未接入。

计划复用个人配置 `~/.pi/agent/pi-voice.json`（目录遵循 `PI_CODING_AGENT_DIR`），
在现有 JSON 中增加字段，不要用以下片段覆盖其他录音设置：

```json
{
  "vocabulary": {
    "cacheCapacity": 128,
    "recordingLimit": 64,
    "extractionLimit": 64
  }
}
```

- 缺失字段使用默认值；删除整个 vocabulary 字段恢复默认配置。
- cacheCapacity：整数 1–1024；另外两个限制：整数 1–128，均不能超过缓存容量。
- 非法值、拼错字段或不一致的组合：整个词表配置回退默认，并返回警告；不破坏录音设置。
- 读取不会自动改写文件；后续保存设置会写入校验后的值。
- 固定/合并词表 128 词、4096 UTF-16 单元、提词输出 512 token 仍是独立保护上限。
- 后续 UX：`/voice-settings` 提供词表设置入口，显示当前值并支持修改和恢复默认。

离线验证：`npm test` 185 项，184 通过、1 跳过。包含缺省、部分覆盖、非法值、
容量关系、文件读写和旧配置兼容；运行时生效与菜单行为留待后续批次验证。
